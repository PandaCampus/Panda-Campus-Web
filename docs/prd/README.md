# PANDA CAMPUS｜校园 Tab PRD 交付包 V1.2

本包是在 V1.1 产品规则基础上对**地点地图同框体验**的增量修订。适用于校园 Tab 及其进入的二级主体与微应用；不改变「胖达」「我」其他页面结构。

## 建议阅读顺序

1. **01_核心摘要/**：读本轮最重要的两态视觉及四业务分类。
2. **02_完整正文/**：用于实现校园 Tab、四类信息、卡片、搜索、筛选、地图、主体关系和页面跳转；重点看第 **08 章**、第 **03 章**和 A19–A23。
3. **03_地点地图专题/**：本轮新增的完整地点状态机、上下栏目约束、渐变磨玻璃、抽屉尺寸、数据接口和 **MAP-01–14** 验收。
4. **04_开发路线与进度/**：M0–M4 第一阶段开发主线与 **M2-P1 地图条件项**、M5–M7 第二阶段；状态由成员自行核对。
5. **05_交接参考/**：用户提供的 `TASK_HANDOFF.md` 为**SFOS 已有任务工作台**的接口说明。仅作为对接约束，未修改已有接口、任务或完成状态。

## 本轮锁定的界面约束

- 校园顶部依次：PANDA CAMPUS/微信原生胶囊 → 头像/触达/消息 → 搜索/筛选/地点 → 全部/就业/商家/社团/活动。
- **默认顶部白底；地图态仅顶部四层背景变渐变磨玻璃，所有控件原位；底部纯文字 Tab 纯白不透明，不加模糊。**
- **只有中间内容视口**由大图卡/橱窗/列表改为地图/地标/地点卡片集合。
- 地图和信息流是同一校园 Tab 的 `feed ⇄ map`；类别、筛选、关键词、卡片 ID 同步，地图非第四档语义缩放。
- 同一地点主体聚合就业(蓝)、商家(黄)、社团/组织名片(紫)、活动(绿)多类卡片。
- 地点地图 V0 仍是有真实校区地点数据后才能上线的 P1 条件项，不阻塞第一阶段主要的搜索浏览/胖达查询。

## 图像与来源约束

参考图中的地图插画用于理解**卡片抽屉、地标和层级**，不是实际学校地形、坐标、可用业务或额外导航设计；骨架图仅作几何参考。正式地图必须由授权底图和核验地点数据生成。

## 文件格式

`.docx` 适合阅读和评审；`.md` 适合进入 Git 仓库。新增的参考图明确标为**仅设计参考，非产品截图**。ZIP 中所有参考文件的内容未被隐式替换成已完成业务数据。
